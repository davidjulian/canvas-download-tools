About Canvas Download Tools

Canvas Download Tools helps instructors collect files and activity logs from Canvas New Quizzes using their own authorized instructor access.

  • Submitted files downloads a submitted file for each student in the current list and adds the student’s name to its filename.
  • Quiz activity logs collects activity logs with named or coded output and a local focus-event summary.

Both tools ask you to check the first download before collecting the rest. Stop preserves completed downloads.

Your files and information stay local

The app stores and processes downloaded files, activity logs, student names, summaries, private name keys and browser sign-in state locally on your computer. Downloads go in the folder you choose; settings and sign-in profiles stay in local app storage.

The app does not upload this information to GitHub, Codex, OpenAI or another AI service. It includes no analytics or remote error reporting. Canvas, file downloads and your institution’s sign-in still use their normal internet connections.
