Releases and prereleases · Source and instructions

Choose your tool

Quiz activity logs: collect View Log text across Moderate student pages, choose named or coded output, and create a local descriptive focus-event summary.

Submitted files: download one learned file per student through SpeedGrader. Filenames begin with the student’s surname, and the original extension is retained.

The same setup on Windows and Mac

  1. Extract the ZIP and run Install once.
  2. Open Start App and choose a tool.
  3. Enter your Canvas address, browser and output folder. Shared settings carry between tools.
  4. Navigate in the separate Canvas window and follow the task’s setup.
  5. Check the first download, then collect the remaining items.

Use Install.cmd and Start App.cmd on Windows, or Install.command and Start App.command on Mac. Mac targets are macOS 14+, Intel and Apple silicon, pending a real platform trial.

Records stay with you

Both tools run locally. This website hosts software instructions only. No student records are sent to GitHub or AI services. Keep private keys, originals, summaries and sign-in profiles restricted. Follow your institution’s storage and retention requirements.

One collection runs at a time. Stop preserves completed downloads. Logs cover recognized Moderate student pages, not hidden events. Submitted files cover one file per student in the current filtered list; earlier attempts and multiple attachments are not collected automatically.
